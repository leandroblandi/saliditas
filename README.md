# Saliditas 🌿
Una aplicación de escritorio útil para gestionar las salidas de predicación en una congregación de Testigos de Jehová. Todo en un solo lugar: conductores, salidas, estadísticas y más...

## Principales funcionalidades ⚙️

- **Gestión de conductores:** En una vista sencilla, la aplicación permite dar de alta nuevos hermanos aptos para conducir salidas, y a la vez poder gestionarlos, es decir, ver en una tabla los que ya están dados de alta. También se puede dar de baja si es necesario.
- **Gestión de salidas:** Crear y gestionar salidas de predicación nunca fue mas fácil, ya que con Saliditas, puedes crear salidas semanales asignando una fecha, lugar, hermano asignado, grupo y otros datos relevantes.
- **Exportación de salidas:** Una necesidad esencial para alguien que gestiona las salidas semanales es exportar en algún formato de utilidad, como Excel o imagen, para poder difundirlo, por eso, Saliditas permite exportar como XLSX/PNG las salidas previamente creadas.
- **Estadísticas de uso:** En una vista tipo resumen, puedes ver algunos "numeros" y gráficos del uso que le das a la aplicación: conductores activos, salidas creadas, etc.
